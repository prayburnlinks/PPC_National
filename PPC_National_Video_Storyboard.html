Recording Tips

TipDetail
Use a real deviceRecord on a physical Android or iPhone for the most realistic look. iOS QuickTime or Android ADB screen capture both work.
Pre-load dataBefore recording, create 4–5 real events, 3–5 prayer requests, and populate giving funds in Firestore so all screens look active.
Set live flagIn Firestore, set the liveStatus.isLive = true field before recording the Media scene so the LIVE badge appears.
ResolutionRecord at 1080p minimum. If using iOS Simulator or Android Emulator, set DPI to match a real device (Pixel 6 / iPhone 14 recommended).
NarrationRecord narration separately and add in post (CapCut, DaVinci Resolve, iMovie). Warm, confident tone — not corporate, church-family voice.
MusicUse royalty-free gospel/worship instrumental. Suggested: search "royalty free gospel instrumental background" on YouTube Audio Library.
Total edit time~2–3 hours in a basic editor to cut, add narration, overlays, and music.
